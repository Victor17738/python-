# Northstar Commercial Bank — Demo

A fictional American-style commercial banking website prototype.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will provide the published Pages address.

## Safety

This project is a visual/demo prototype only. It does not connect to a bank, process transactions, store credentials, or provide real financial services. Do not enter real banking information.
